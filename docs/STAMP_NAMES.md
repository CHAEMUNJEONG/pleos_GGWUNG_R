# 스탬프 자동 이름 검증

`StampNameResolver`는 이번 주행 중 수신한 목적지명 중 최근 10분 이내, 주차 지점에서
500m 이내인 유효 좌표의 이름을 먼저 사용한다. 조건을 충족하지 않으면 이번 주행 중
받은 최근 주소를 사용하고, 주소도 없으면 기존 `새로운 장소 N` 이름을 유지한다.
10분/500m는 개발용 정책 상수이며 팀 검증 후 조정할 수 있다.

SDK의 도착 좌표를 `ArrivedPlace`로 전달한다. 빈 주소 콜백은 이전 주소를 지우며
주소 수신 시각을 별도로 기록한다. 시뮬레이터도 도착 좌표를 제공하고 출발할 때 이전 도착을 지운다.
장소 중복 방지, 사용자 편집, 지도·저장 형식은 기존 동작을 유지한다.

단위테스트는 목적지 우선·주소 대체·기본 이름, 이전 주행·미래·오래된 이벤트,
먼/잘못된 좌표, 빈 이름, 시뮬레이터 도착 전달, 중복 장소를 검사한다.

실제 SDK E2E 확인은 별도로 한다.

1. 내비 경로를 주행해 목적지 도착 콜백을 받는다.
2. 최소 저장 거리 이상 주행한 뒤 주차한다.
3. 새 스탬프 이름이 목적지명인지 확인한다.
4. 앱을 재시작해 이름·메모가 유지되는지 확인한다.
5. 내비가 없는 주행, 도착 이벤트가 없는 주행, 오래되거나 다른 장소의 도착에서도
   주소 또는 기본 이름으로 안전하게 대체되는지 확인한다.

콜백을 주입하는 단위테스트나 서비스 연결 성공만으로 실제 도착·저장 E2E를 완료로 표시하지 않는다.
